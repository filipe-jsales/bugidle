# BugIdle

Idle "bug hunter" game in the browser: your bugs fight on their own along routes, you catch new ones, fill the Bugdex and beat bosses to open new regions.

**Before changing anything, read [docs/instructions.md](docs/instructions.md)** (architecture, rules, how to verify a feature) and update [docs/backlog.md](docs/backlog.md) when a task is done or a new one appears.

Quick commands:

```
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests (Vitest)
npm run typecheck
npm run build
```
